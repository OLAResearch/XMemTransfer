OLA Research • XMemTransfer

Frozen memory is not enough.

XMemTransfer studies whether an Engram-style external memory remains useful after it is detached from the model that trained it and attached to a different backbone. Across architectures, tokenizers, and scales, the project shows that portability is ultimately an extraction problem: the frozen table matters, but a strong target-side reader is what turns stored signal into usable performance.

Highlights

Cross-backbone transfer

Every source-target pair in the main matrix improves over its no-memory baseline, including cross-tokenizer settings.

Reader-first view

Stronger target-side readers nearly close the gap between same-model and cross-model reuse, which shifts the interpretation from “stored memory only” to “stored memory plus extraction.”

Selective downstream gains

Improvements are strongest on knowledge-intensive tasks with factual recall or reasoning demands, while truthfulness-sensitive evaluation remains a visible boundary case.
